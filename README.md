# LocalKit Demo

The free demo app for [LocalKit](https://localkit.gamefix.dev), a SwiftUI starter kit for iOS apps with an on-device language model.

The demo runs with a mock engine so it works in the simulator with no download. The full kit adds the real MLX engine, model management, memory guard, and the paywall.

Status: in progress. Watch this repo or join the list at https://localkit.gamefix.dev

## What the paid kit adds

- Model download with resume and checksum verification
- Per-device memory guard that refuses a model that will not fit instead of crashing
- Streaming chat with real cancellation
- StoreKit 2 paywall, onboarding, settings
- Privacy manifest and App Store checklist
- Commercial license, unlimited apps
